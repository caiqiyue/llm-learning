GPT-2 的损失函数，本质上就是一句话：

**让当前位置的输出 logits 去预测下一个 token。**

也就是：

```text
第 0 个位置的输出 -> 预测第 1 个 token
第 1 个位置的输出 -> 预测第 2 个 token
第 2 个位置的输出 -> 预测第 3 个 token
...
```

所以 GPT-2 训练的任务叫：

```text
next token prediction
```

也就是“下一个 token 预测”。

---

# 1. 先看输入和目标

假设一句话 token 化之后是：

```text
tokens = [我, 喜欢, 机器, 学习]
```

对应 id 假设是：

```text
[10, 23, 31, 42]
```

GPT-2 的训练目标不是一次性判断整句话对不对，而是让模型学会：

```text
看到「我」          -> 预测「喜欢」
看到「我 喜欢」     -> 预测「机器」
看到「我 喜欢 机器」 -> 预测「学习」
```

所以训练样本可以理解成：

```text
输入位置        要预测的目标
tokens[0]  ->  tokens[1]
tokens[1]  ->  tokens[2]
tokens[2]  ->  tokens[3]
```

也就是：

```text
我      -> 喜欢
喜欢    -> 机器
机器    -> 学习
```

---

# 2. logits 是什么？

模型 forward 后输出：

```python
logits = ...  # [B, T, V]
```

其中：

```text
B = batch size，一批有多少句话
T = sequence length，每句话有多少 token
V = vocab size，词表大小
```

比如：

```text
B = 2
T = 5
V = 45
```

那么：

```text
logits.shape = [2, 5, 45]
```

意思是：

```text
2 条样本
每条样本 5 个位置
每个位置输出 45 个 token 的分数
```

每一个位置的 `logits` 都是一个长度为 `V` 的向量：

```text
logits[b, t, :] = 当前 batch 第 b 条样本，第 t 个位置，对所有 vocab token 的预测分数
```

比如：

```text
logits[0, 2, :]
```

表示：

```text
第 0 条样本，第 2 个位置，预测下一个 token 时，对整个词表的打分。
```

---

# 3. 为什么要错位一位？

你的代码：

```python
logits = logits[:, :-1, :].contiguous()
targets = targets[:, 1:].contiguous()
```

这是 GPT 损失函数最关键的一步。

假设原始 tokens 是：

```text
[我, 喜欢, 机器, 学习]
```

模型输出的 logits 有 4 个位置：

```text
logits[0]：看到「我」之后的预测
logits[1]：看到「我 喜欢」之后的预测
logits[2]：看到「我 喜欢 机器」之后的预测
logits[3]：看到「我 喜欢 机器 学习」之后的预测
```

但是训练时：

```text
logits[0] 应该预测 token[1] = 喜欢
logits[1] 应该预测 token[2] = 机器
logits[2] 应该预测 token[3] = 学习
```

最后一个：

```text
logits[3]
```

没有下一个 token 可以预测，所以要去掉。

因此：

```python
logits = logits[:, :-1, :]
```

意思是：

```text
去掉最后一个位置的 logits
```

原来：

```text
logits 对应位置: 0, 1, 2, 3
```

变成：

```text
logits 对应位置: 0, 1, 2
```

---

而 target 要从第二个 token 开始：

```python
targets = targets[:, 1:]
```

原始 targets：

```text
[我, 喜欢, 机器, 学习]
```

错位后：

```text
[喜欢, 机器, 学习]
```

于是对齐关系变成：

```text
logits[0] -> target[0] = 喜欢
logits[1] -> target[1] = 机器
logits[2] -> target[2] = 学习
```

这就是“错位一位”的含义。

# 4. 用表格看最清楚

假设输入：

```text
tokens = [我, 喜欢, 机器, 学习]
```

模型输出：


| 位置 | 输入 token | 这个位置的 logits 应该预测 |
| ---- | ---------- | -------------------------- |
| 0    | 我         | 喜欢                       |
| 1    | 喜欢       | 机器                       |
| 2    | 机器       | 学习                       |
| 3    | 学习       | 没有下一个 token，丢掉     |

所以：

```python
logits[:, :-1, :]
```

保留：

```text
位置 0, 1, 2
```

```python
targets[:, 1:]
```

保留：

```text
喜欢, 机器, 学习
```

最终就是：

```text
logits[位置 0] 预测 喜欢
logits[位置 1] 预测 机器
logits[位置 2] 预测 学习
```

# 5. Cross Entropy 到底怎么算？

代码：

```python
loss = F.cross_entropy(
    logits.view(-1, V),
    targets.view(-1),
    ignore_index=-1
)
```

`cross_entropy` 做的是：

```text
先对 logits 做 softmax，得到概率分布；
然后看正确 token 的概率有多大；
正确 token 概率越大，loss 越小；
正确 token 概率越小，loss 越大。
```

比如某个位置，词表只有 5 个 token：

```text
0: 我
1: 喜欢
2: 机器
3: 学习
4: 猫
```

模型在当前位置输出 logits，softmax 后得到概率：

```text
我:   0.05
喜欢: 0.70
机器: 0.10
学习: 0.10
猫:   0.05
```

如果正确答案是：

```text
喜欢
```

那么这个位置的 loss 是：

```text
-loss = -log(0.70)
```

约等于：

```text
0.357
```

如果模型给正确答案的概率很低，比如：

```text
喜欢: 0.01
```

那么 loss 是：

```text
-log(0.01) ≈ 4.605
```

就很大。

所以 cross entropy 的直觉是：

```text
模型越相信正确答案，loss 越小；
模型越不相信正确答案，loss 越大。
```

# 6. 为什么要 view(-1, V)？

原始 logits 是三维：

```python
logits.shape = [B, T-1, V]
```

比如：

```text
B = 2
T = 5
V = 45
```

错位后：

```text
logits.shape = [2, 4, 45]
targets.shape = [2, 4]
```

但是 PyTorch 的 `F.cross_entropy` 通常希望输入是：

```text
[N, C]
```

其中：

```text
N = 样本数量
C = 类别数量
```

对于语言模型来说：

```text
每一个 token 位置都是一个分类样本
类别数量就是 vocab size
```

所以要把：

```text
[B, T-1, V]
```

展平成：

```text
[B * (T-1), V]
```

也就是：

```python
logits.view(-1, V)
```

例如：

```text
[2, 4, 45] -> [8, 45]
```

意思是：

```text
一共有 8 个 token 位置需要预测；
每个位置对 45 个词表 token 打分。
```

targets 也要对应展平：

```python
targets.view(-1)
```

从：

```text
[2, 4]
```

变成：

```text
[8]
```

意思是：

```text
这 8 个位置各自的正确 token id。
```

# 7. 展平前后其实没有改变语义

假设 batch 里有两句话：

```text
样本 1: [我, 喜欢, 机器, 学习]
样本 2: [你, 喜欢, 深度, 学习]
```

错位后目标是：

```text
样本 1 target: [喜欢, 机器, 学习]
样本 2 target: [喜欢, 深度, 学习]
```

展平后变成：

```text
[
  喜欢,
  机器,
  学习,
  喜欢,
  深度,
  学习
]
```

每个位置独立算一个 cross entropy，然后取平均。

所以 GPT-2 的 loss 本质上是：

```text
所有有效 token 位置的 next-token prediction loss 的平均值。
```

# 8. ignore\_index=-1 是什么？

`ignore_index=-1` 的意思是：

```text
如果某个 target 的值是 -1，那么这个位置不参与 loss 计算。
```

它通常用于 padding。

比如 batch 里句子长度不一样：

```text
样本 1: [我, 喜欢, 机器, 学习]
样本 2: [你好]
```

为了组成 batch，需要补齐长度。

可能变成：

```text
样本 1: [我, 喜欢, 机器, 学习]
样本 2: [你好, PAD, PAD, PAD]
```

如果 PAD 也参与 loss，模型就会被迫学习预测 PAD，这没有意义。

所以可以把 padding 位置的 target 设置成：

```text
-1
```

例如：

```text
样本 2 target: [PAD, PAD, PAD]
```

可以处理成：

```text
样本 2 target: [-1, -1, -1]
```

然后：

```python
ignore_index=-1
```

就会告诉 PyTorch：

```text
target = -1 的位置直接跳过，不算 loss，不反传梯度。
```

# 9. 为什么 target 不是 one-hot？

在分类任务里，你可能以为 target 应该是 one-hot，比如：

```text
正确答案是「喜欢」
```

词表大小 5，就写成：

```text
[0, 1, 0, 0, 0]
```

但是 PyTorch 的 `F.cross_entropy` 不需要你传 one-hot。

它需要的是正确类别的 id：

```text
target = 1
```

所以：

```python
targets.view(-1)
```

的 shape 是：

```text
[B * (T-1)]
```

而不是：

```text
[B * (T-1), V]
```

也就是说：

```text
logits:  每个位置对所有词表 token 的预测分数
targets: 每个位置的正确 token id
```

# 10. `.contiguous()` 是干什么的？

代码里有：

```python
logits = logits[:, :-1, :].contiguous()
targets = targets[:, 1:].contiguous()
```

这里 `.contiguous()` 不是损失函数的核心逻辑，它主要是为了保证内存连续。

因为：

```python
logits[:, :-1, :]
```

这种切片操作可能得到一个非连续内存的 view。

后面要用：

```python
logits.view(-1, V)
```

`view` 通常要求 tensor 在内存中是连续的。

所以加：

```python
.contiguous()
```

是为了安全地 reshape。

简单理解：

```text
contiguous 是为了让后面的 view 不出问题。
```

# 11. 完整流程再过一遍

假设：

```text
input_ids = [我, 喜欢, 机器, 学习]
targets   = [我, 喜欢, 机器, 学习]
```

模型 forward：

```python
logits = model(input_ids)
```

得到：

```text
logits.shape = [B, T, V]
```

然后错位：

```python
logits = logits[:, :-1, :]
targets = targets[:, 1:]
```

变成：

```text
logits: 位置 [我, 喜欢, 机器]
targets: [喜欢, 机器, 学习]
```

对齐关系：

```text
看到 我      -> 预测 喜欢
看到 喜欢    -> 预测 机器
看到 机器    -> 预测 学习
```

展平：

```python
logits = logits.view(-1, V)
targets = targets.view(-1)
```

然后计算：

```python
loss = F.cross_entropy(logits, targets, ignore_index=-1)
```

最终得到一个标量：

```text
loss = 一个数字
```

这个数字越小，说明模型对下一个 token 的预测越准。

# 12. 你可以把 GPT-2 loss 理解成考试

假设题目是：

```text
我 喜欢 机器 学习
```

模型要做填空题：

```text
我      -> ______
我 喜欢 -> ______
我 喜欢 机器 -> ______
```

标准答案是：

```text
喜欢
机器
学习
```

模型每个位置都给出一个词表概率分布。

如果模型预测：

```text
喜欢: 0.8
机器: 0.7
学习: 0.9
```

loss 就小。

如果模型预测：

```text
喜欢: 0.01
机器: 0.02
学习: 0.03
```

loss 就大。

这就是 GPT-2 的训练目标。

# 13. 最重要的总结

这段代码：

```python
logits = logits[:, :-1, :].contiguous()
targets = targets[:, 1:].contiguous()
loss = F.cross_entropy(
    logits.view(-1, V),
    targets.view(-1),
    ignore_index=-1
)
```

可以翻译成中文：

```text
把模型每个位置的输出 logits 往后错一位，
让第 t 个位置的 logits 去预测第 t+1 个 token；
最后一个 logits 没有下一个 token，丢掉；
第一个 target 没有前一个位置预测它，丢掉；
把所有 batch、所有位置展平成一堆分类样本；
对每个位置做 vocab 分类；
忽略 padding 位置；
求平均 cross entropy。
```

最核心的一句话：

```text
GPT-2 的 loss = 每个位置预测下一个 token 的交叉熵损失的平均值。
```
