这一块你可以先建立一个总框架：

```text
参数初始化：训练开始前，模型参数从哪里出发
Loss：告诉模型现在错得有多离谱
反向传播：算出每个参数应该往哪个方向改
Optimizer：根据梯度真正更新参数
Scheduler：控制每一步 optimizer 用多大的学习率
```

最核心的关系是：

```text
初始化决定起点
optimizer 决定怎么走
scheduler 决定每一步走多大
loss 决定走的方向
```

---

# 1. 一次训练迭代到底发生了什么？

假设模型参数统一记作：

```text
θ
```

也就是所有权重参数，包括：

```text
token embedding
position embedding
attention 里的 Wq/Wk/Wv/Wo
MLP 里的 Linear 权重
LayerNorm 参数
lm_head 权重
```

一次训练大概是：

```python
# 1. 前向传播
logits, loss = model(x, y)

# 2. 反向传播，计算梯度
loss.backward()

# 3. scheduler 给出当前学习率
lr = get_lr(step)

# 4. optimizer 使用这个 lr 更新参数
optimizer.step()

# 5. 清空梯度
optimizer.zero_grad()
```

用数学写就是：

```text
当前参数 θ_t
      ↓
前向传播算 loss
      ↓
反向传播算梯度 g_t
      ↓
optimizer 根据 g_t 更新 θ_t
      ↓
得到新的参数 θ_{t+1}
```

其中梯度是：

```text
g_t = ∇_θ L(θ_t)
```

意思是：

```text
当前 loss 对参数 θ 的导数
```

梯度告诉模型：

```text
哪些参数应该变大
哪些参数应该变小
应该变多少方向
```

---

# 2. 最基本公式：梯度下降 Gradient Descent

最基础的参数更新公式是：

```text
θ_{t+1} = θ_t - η · g_t
```

其中：

```text
θ_t：第 t 步的参数
g_t：当前梯度
η：学习率 learning rate
```

这个公式非常重要。

它的意思是：

```text
参数沿着 loss 下降最快的方向走一步。
```

为什么是减号？

因为梯度方向是 loss 上升最快的方向。

所以要降低 loss，就往反方向走：

```text
参数 = 参数 - 学习率 × 梯度
```

举个例子：

```text
θ = 1.0
g = 0.2
η = 0.1
```

更新：

```text
θ_new = 1.0 - 0.1 × 0.2 = 0.98
```

所以参数从 1.0 变成 0.98。

---

# 3. SGD：最基础的 optimizer

SGD 全称是：

```text
Stochastic Gradient Descent
```

随机梯度下降。

它的公式就是：

```text
θ_{t+1} = θ_t - η · g_t
```

为什么叫 stochastic？

因为实际训练时不是用全部训练数据算梯度，而是用一个 mini-batch。

例如你的训练集有 100 万条数据，不可能每次都全部算一遍，所以每次取一个 batch：

```text
batch_size = 32 / 64 / 128
```

用这一个 batch 估计整体梯度。

所以 SGD 的特点是：

```text
简单
直接
噪声较大
对学习率敏感
```

它在传统深度学习、CNN 训练里很常见，但 GPT/Transformer 训练里通常不是首选。

---

# 4. Momentum：带惯性的 SGD

普通 SGD 的问题是：

```text
每一步只看当前梯度，容易左右震荡。
```

Momentum 的思想是：

```text
不要只看当前梯度，也要记住过去的更新方向。
```

公式是：

```text
v_t = β · v_{t-1} + g_t
```

```text
θ_{t+1} = θ_t - η · v_t
```

其中：

```text
v_t：动量，也可以理解成速度
β：动量系数，常见 0.9
g_t：当前梯度
```

直觉上：

```text
如果很多步的梯度都朝同一个方向，速度会越来越大；
如果梯度一会儿左一会儿右，震荡会被抵消。
```

你可以把它理解成“小球下山”。

SGD 是：

```text
每一步只看脚下坡度。
```

Momentum 是：

```text
小球有惯性，会沿着长期稳定的方向冲下去。
```

---

# 5. RMSProp：不同参数用不同步长

SGD 和 Momentum 有一个问题：

```text
所有参数都用同一个学习率。
```

但是在神经网络里，不同参数的梯度尺度可能差别很大。

有些参数梯度一直很大。

有些参数梯度一直很小。

RMSProp 会记录梯度平方的滑动平均：

```text
s_t = β · s_{t-1} + (1 - β) · g_t^2
```

更新：

```text
θ_{t+1} = θ_t - η · g_t / sqrt(s_t + ε)
```

其中：

```text
s_t：历史梯度平方的平均
ε：很小的数，防止除以 0
```

直觉：

```text
如果某个参数梯度长期很大，就把它的步子缩小；
如果某个参数梯度长期较小，就相对给它更大的有效步子。
```

这叫：

```text
自适应学习率
```

---

# 6. Adam：Momentum + RMSProp

Adam 是现在深度学习里最常用的 optimizer 之一。

它可以理解成：

```text
Adam = Momentum + RMSProp
```

它同时维护两个量：

```text
m_t：一阶动量，梯度的滑动平均
v_t：二阶动量，梯度平方的滑动平均
```

公式：

```text
m_t = β_1 · m_{t-1} + (1 - β_1) · g_t
```

```text
v_t = β_2 · v_{t-1} + (1 - β_2) · g_t^2
```

其中常见超参是：

```text
β_1 = 0.9
β_2 = 0.999
ε = 1e-8
```

`m_t` 负责记住方向：

```text
过去梯度大多往哪里走？
```

`v_t` 负责调整步长：

```text
这个参数的梯度尺度大不大？
```

但是训练刚开始时，`m_t` 和 `v_t` 都从 0 开始，会偏小，所以 Adam 有偏差修正：

```text
m_hat_t = m_t / (1 - β_1^t)
```

```text
v_hat_t = v_t / (1 - β_2^t)
```

最终更新：

```text
θ_{t+1} = θ_t - η · m_hat_t / (sqrt(v_hat_t) + ε)
```

你可以这样理解 Adam：

```text
m_hat_t：我应该往哪个方向走
sqrt(v_hat_t)：这个方向上的梯度尺度有多大
η：整体步子大小
```

Adam 的优势是：

```text
收敛快
对学习率没 SGD 那么敏感
适合 Transformer
```

---

# 7. AdamW：GPT/Transformer 最常用 optimizer

训练 GPT、BERT、ViT 这类模型，最常见的是：

```text
AdamW
```

AdamW = Adam + decoupled weight decay。

先解释 weight decay。

---

## 7.1 Weight Decay 是什么？

Weight Decay 中文叫权重衰减。

它的作用是：

```text
不要让权重参数变得过大。
```

权重太大可能导致：

```text
过拟合
训练不稳定
泛化变差
```

传统 L2 正则化是给 loss 加一项：

```text
L_total = L_data + λ/2 · ||θ||²
```

其中：

```text
L_data：原本的训练 loss
λ：weight decay 系数
||θ||²：所有参数平方和
```

对这个正则项求导，会多出：

```text
λθ
```

所以 SGD 里的更新会变成：

```text
θ_{t+1} = θ_t - η · (g_t + λθ_t)
```

意思是：

```text
除了沿着梯度更新，还额外把参数往 0 拉一点。
```

---

## 7.2 AdamW 和 Adam 的区别

普通 Adam 如果直接把 weight decay 混进梯度里，会和 Adam 的自适应缩放耦合在一起。

AdamW 的做法是：

```text
梯度更新归梯度更新
权重衰减归权重衰减
两者分开做
```

AdamW 更新可以理解成：

```text
θ_{t+1} = θ_t - η · AdamUpdate(g_t) - η · λ · θ_t
```

其中：

```text
AdamUpdate(g_t) = m_hat_t / (sqrt(v_hat_t) + ε)
```

所以完整写：

```text
θ_{t+1}
= θ_t
- η · m_hat_t / (sqrt(v_hat_t) + ε)
- η · λ · θ_t
```

这就是 AdamW 的核心。

你可以这样记：

```text
Adam：负责根据梯度更新参数
W：额外让权重变小一点，防止参数过大
```

GPT 类模型常用组合：

```text
AdamW + Warmup + Cosine Decay
```

---

# 8. Scheduler 是什么？

Optimizer 决定：

```text
怎么根据梯度更新参数
```

Scheduler 决定：

```text
每一步用多大的学习率 η_t
```

注意学习率不是必须固定不变的。

训练第 1 步和第 10000 步，用的学习率可以不一样。

所以公式从：

```text
θ_{t+1} = θ_t - η · g_t
```

变成：

```text
θ_{t+1} = θ_t - η_t · g_t
```

这里的：

```text
η_t
```

就是第 t 步的学习率，由 scheduler 决定。

---

# 9. Warmup Scheduler

Warmup 的公式是：

```text
η_t = η_max · t / T_w
```

其中：

```text
η_t：第 t 步学习率
η_max：峰值学习率
T_w：warmup 步数
```

例如：

```text
η_max = 3e-4
T_w = 200
```

那么：

```text
第 0 步：0
第 100 步：1.5e-4
第 200 步：3e-4
```

Warmup 的作用是：

```text
训练初期模型参数随机，梯度不稳定；
先用小学习率慢慢热身；
避免一开始大学习率把模型冲坏。
```

尤其是 Transformer、大模型训练，warmup 很常见。

---

# 10. Cosine Decay Scheduler

Warmup 结束后，常接 cosine decay。

公式是：

```text
decay_ratio = (t - T_w) / (T_max - T_w)
```

```text
coeff = 0.5 · (1 + cos(π · decay_ratio))
```

```text
η_t = η_min + coeff · (η_max - η_min)
```

其中：

```text
T_w：warmup 结束步数
T_max：衰减结束步数
η_max：最大学习率
η_min：最小学习率
```

当：

```text
decay_ratio = 0
```

有：

```text
cos(0) = 1
coeff = 1
η_t = η_max
```

当：

```text
decay_ratio = 1
```

有：

```text
cos(π) = -1
coeff = 0
η_t = η_min
```

所以 cosine decay 的过程是：

```text
从 η_max 平滑下降到 η_min
```

它的优点是：

```text
下降平滑
前期下降慢，保留探索能力
中期逐渐降低
后期小学习率精修
```

---

# 11. 常见 Scheduler 对比

常见的学习率调度有几种：


| Scheduler       | 公式直觉                | 常见场景               |
| --------------- | ----------------------- | ---------------------- |
| Constant LR     | 学习率固定不变          | 简单实验               |
| Step Decay      | 每隔一段时间乘一个系数  | CNN 经典训练           |
| Linear Decay    | 线性下降到 0 或 min\_lr | BERT、NLP 常见         |
| Cosine Decay    | 余弦平滑下降            | GPT、ViT、现代训练常见 |
| Warmup + Linear | 先升后线性降            | BERT 常见              |
| Warmup + Cosine | 先升后余弦降            | GPT/Transformer 常见   |

GPT 里你重点记：

```text
Warmup + Cosine
```

---

# 12. 参数初始化是什么？

参数初始化是在训练开始前给权重一个初始值。

比如：

```python
nn.Linear(...)
nn.Embedding(...)
```

这些层刚创建时，里面的权重不能全是空的，需要初始化。

参数初始化很关键，因为它决定：

```text
模型训练的起点
前向传播信号是否稳定
反向传播梯度是否稳定
不同神经元是否能学到不同东西
```

---

# 13. 为什么不能全部初始化为 0？

假设一层有很多神经元，如果权重全部是 0，那么每个神经元输出一样，梯度也一样，更新也一样。

结果是：

```text
所有神经元永远学一样的东西。
```

这叫：

```text
symmetry problem，对称性问题
```

所以权重一般不能全 0。

但是 bias 可以初始化为 0，因为 bias 不会导致神经元权重完全对称。

常见做法：

```text
weight：随机初始化
bias：初始化为 0
LayerNorm gamma：初始化为 1
LayerNorm beta：初始化为 0
```

---

# 14. 初始化的核心目标：保持方差稳定

神经网络一层一层传递。

如果初始化太大，会导致：

```text
激活值越来越大
梯度越来越大
训练爆炸
```

如果初始化太小，会导致：

```text
激活值越来越小
梯度越来越小
训练很慢甚至学不动
```

所以好的初始化要让信号在层与层之间保持稳定。

目标大概是：

```text
输入经过一层后，输出方差不要突然变大或变小。
```

这就是 Xavier 和 Kaiming 初始化的核心思想。

---

# 15. Xavier / Glorot 初始化

Xavier 初始化常用于：

```text
tanh / sigmoid / 线性激活
```

它希望同时考虑输入维度和输出维度。

定义：

```text
fan_in：输入维度
fan_out：输出维度
```

Xavier Normal：

```text
W ~ N(0, 2 / (fan_in + fan_out))
```

意思是：

```text
权重服从均值为 0，方差为 2/(fan_in + fan_out) 的正态分布。
```

标准差是：

```text
std = sqrt(2 / (fan_in + fan_out))
```

Xavier Uniform：

```text
W ~ U(-a, a)
```

其中：

```text
a = sqrt(6 / (fan_in + fan_out))
```

直觉：

```text
输入输出维度越大，单个权重就应该越小。
```

因为如果维度很大，每个输出是很多输入的加权和，权重太大会导致输出爆炸。

---

# 16. Kaiming / He 初始化

Kaiming 初始化常用于：

```text
ReLU / LeakyReLU
```

因为 ReLU 会把一部分负数变成 0，相当于丢掉一半信号，所以初始化需要稍微调整。

Kaiming Normal：

```text
W ~ N(0, 2 / fan_in)
```

标准差：

```text
std = sqrt(2 / fan_in)
```

Kaiming Uniform 也有对应版本。

它的直觉是：

```text
ReLU 会砍掉一部分激活，所以权重方差需要按 2/fan_in 设置。
```

CNN、MLP 里如果用 ReLU，Kaiming 很常见。

---

# 17. GPT / Transformer 常见初始化

GPT 类模型里，常见初始化更像：

```text
Linear weight: Normal(0, 0.02)
Embedding weight: Normal(0, 0.02)
Bias: 0
LayerNorm weight gamma: 1
LayerNorm bias beta: 0
```

也就是：

```python
nn.init.normal_(linear.weight, mean=0.0, std=0.02)
nn.init.normal_(embedding.weight, mean=0.0, std=0.02)
nn.init.zeros_(linear.bias)
nn.init.ones_(layernorm.weight)
nn.init.zeros_(layernorm.bias)
```

这里：

```text
Normal(0, 0.02)
```

意思是：

```text
从均值为 0，标准差为 0.02 的正态分布中随机采样。
```

也就是大部分参数一开始都在比较小的范围内。

---

# 18. 为什么 Transformer 里经常用小的 normal 初始化？

Transformer 层数比较深。

每一层都有：

```text
attention residual
MLP residual
LayerNorm
```

如果一开始权重太大，残差不断累加，激活可能变得不稳定。

所以 GPT 类模型常用较小标准差，比如：

```text
std = 0.02
```

一些实现还会对 residual projection 做特殊缩放。

例如某些 GPT 实现会对残差路径上的输出投影使用：

```text
std = 0.02 / sqrt(2 · n_layer)
```

其中：

```text
n_layer：Transformer block 层数
```

直觉是：

```text
层数越深，每层残差贡献应该越小一点；
否则很多层叠加后容易让激活尺度变大。
```

---

# 19. Embedding 初始化

Token embedding 是一个矩阵：

```text
[vocab_size, n_embd]
```

比如：

```text
[50257, 768]
```

初始化通常是：

```text
E ~ N(0, 0.02)
```

训练刚开始时，每个 token 的向量是随机的。

随着训练进行：

```text
经常在相似上下文出现的 token，其 embedding 会被训练得更接近。
```

Position embedding 如果是 learned positional embedding，也类似：

```text
P ~ N(0, 0.02)
```

如果是 sinusoidal positional encoding，则不是随机初始化，而是公式生成，通常不训练。

---

# 20. LayerNorm 参数初始化

LayerNorm 有两个可学习参数：

```text
gamma
beta
```

LayerNorm 公式是：

```text
y = gamma · (x - mean) / sqrt(var + eps) + beta
```

初始化通常是：

```text
gamma = 1
beta = 0
```

为什么？

因为这样一开始 LayerNorm 做的就是标准化本身，不额外改变尺度和平移。

```text
gamma = 1：保持标准化后的尺度
beta = 0：不额外平移
```

---

# 21. 权重初始化和 optimizer 的关系

初始化决定：

```text
训练从哪里开始
```

optimizer 决定：

```text
训练怎么移动
```

scheduler 决定：

```text
每一步移动多大
```

举个类比：

```text
初始化：你一开始站在哪个山坡位置
optimizer：你采用什么下山策略
scheduler：你每一步迈多大
loss landscape：整个山的地形
```

如果初始化很差：

```text
站在悬崖边
梯度爆炸
loss 直接 NaN
```

如果学习率太大：

```text
一步迈太远，跳过最优点，甚至发散
```

如果 optimizer 不合适：

```text
走得慢，震荡大，收敛差
```

所以三者必须配合。

# 22. GPT 训练里还有几个重要训练技巧

除了 optimizer、scheduler、初始化，还有几个训练时非常重要的东西。

---

## 22.1 Gradient Clipping：梯度裁剪

有时候梯度会突然非常大。

如果直接更新参数，可能导致训练爆炸。

梯度裁剪做的是：

```text
如果梯度范数超过阈值，就整体缩小梯度。
```

公式：

```text
if ||g|| > c:
    g = c · g / ||g||
```

其中：

```text
c：clip 阈值，比如 1.0
```

PyTorch 里常见：

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

直觉：

```text
梯度方向不变，只限制梯度长度不要太夸张。
```

---

## 22.2 Gradient Accumulation：梯度累积

如果显存不够，不能用很大的 batch size，可以用梯度累积。

例如你想要等效 batch size = 128，但显存只能放 batch size = 32。

可以：

```text
连续跑 4 个小 batch
每次 backward 累积梯度
第 4 次再 optimizer.step()
```

等效于：

```text
batch_size 32 × accumulation_steps 4 = 128
```

核心代码：

```python
loss = loss / accumulation_steps
loss.backward()

if step % accumulation_steps == 0:
    optimizer.step()
    optimizer.zero_grad()
```

---

## 22.3 Mixed Precision：混合精度训练

常见是：

```text
FP16 / BF16
```

好处：

```text
显存更省
速度更快
```

但要注意数值稳定性。

现在训练 Transformer 常用：

```text
BF16 优先
FP16 需要 loss scaling
```

---

## 22.4 Weight Decay 参数分组

GPT 训练里不是所有参数都加 weight decay。

通常：

```text
Linear weight：加 weight decay
bias：不加
LayerNorm weight：不加
Embedding：有些实现加，有些不加
```

常见分组：

```python
decay_params = []
no_decay_params = []

for name, param in model.named_parameters():
    if name.endswith("bias"):
        no_decay_params.append(param)
    elif "ln" in name or "norm" in name:
        no_decay_params.append(param)
    else:
        decay_params.append(param)
```

原因是：

```text
bias 和 LayerNorm 参数本来就很小，且作用特殊；
对它们做 weight decay 往往收益不大，甚至有害。
```

# 23. 把这些内容放进 GPT 训练流程

一个比较完整的 GPT 训练流程是：

```python
# 1. 初始化模型参数
model = GPT(config)
model.apply(init_weights)

# 2. 创建 optimizer
optimizer = AdamW(
    model.parameters(),
    lr=config.learning_rate,
    betas=(0.9, 0.95),
    weight_decay=0.1
)

for step in range(max_iters):
    # 3. 获取 batch
    x, y = get_batch()

    # 4. 前向传播
    logits, loss = model(x, y)

    # 5. 反向传播
    loss.backward()

    # 6. 梯度裁剪
    clip_grad_norm_(model.parameters(), 1.0)

    # 7. scheduler 设置当前 lr
    lr = get_lr(step)
    for group in optimizer.param_groups:
        group["lr"] = lr

    # 8. optimizer 更新参数
    optimizer.step()

    # 9. 清空梯度
    optimizer.zero_grad()
```

完整逻辑是：

```text
先初始化参数
每一步算 loss
loss.backward 得到梯度
scheduler 决定当前 lr
optimizer 使用梯度和 lr 更新参数
```

# 24. 你最应该背下来的公式

## 梯度下降

```text
θ_{t+1} = θ_t - η · g_t
```

---

## Momentum

```text
v_t = β · v_{t-1} + g_t
```

```text
θ_{t+1} = θ_t - η · v_t
```

---

## Adam

```text
m_t = β_1 · m_{t-1} + (1 - β_1) · g_t
```

```text
v_t = β_2 · v_{t-1} + (1 - β_2) · g_t²
```

```text
m_hat_t = m_t / (1 - β_1^t)
```

```text
v_hat_t = v_t / (1 - β_2^t)
```

```text
θ_{t+1} = θ_t - η · m_hat_t / (sqrt(v_hat_t) + ε)
```

---

## AdamW

```text
θ_{t+1}
= θ_t
- η · m_hat_t / (sqrt(v_hat_t) + ε)
- η · λ · θ_t
```

---

## Warmup

```text
η_t = η_max · t / T_w
```

---

## Cosine Decay

```text
η_t = η_min + 0.5 · (η_max - η_min) · [1 + cos(π · decay_ratio)]
```

其中：

```text
decay_ratio = (t - T_w) / (T_max - T_w)
```

---

## Xavier 初始化

```text
Var(W) = 2 / (fan_in + fan_out)
```

```text
std = sqrt(2 / (fan_in + fan_out))
```

---

## Kaiming 初始化

```text
Var(W) = 2 / fan_in
```

```text
std = sqrt(2 / fan_in)
```

---

## GPT 常见初始化

```text
W ~ N(0, 0.02)
```

```text
bias = 0
LayerNorm gamma = 1
LayerNorm beta = 0
```

# 25. 最后用一句话总结

训练 GPT 时，这几件事的关系是：

```text
初始化负责给模型一个稳定起点；
loss 负责衡量预测错得多严重；
反向传播负责算出每个参数的梯度；
optimizer 负责根据梯度更新参数；
scheduler 负责控制每一步学习率；
weight decay 和 gradient clipping 负责让训练更稳定、更不容易过拟合或爆炸。
```

你可以把核心组合记成：

```text
GPT/Transformer 训练常用配置：
AdamW + Warmup + Cosine Decay + 小方差 Normal 初始化 + Gradient Clipping
```

最重要的理解是：

```text
optimizer 不是学习率；
scheduler 也不是 optimizer；
初始化也不是训练更新。
```

它们分别负责：

```text
初始化：从哪里开始
optimizer：怎么走
scheduler：每一步走多大
```
