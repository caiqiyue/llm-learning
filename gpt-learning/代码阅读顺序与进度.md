| 10 | [`model/gpt2.py`](gpt-learning-pytorch/model/gpt2.py)             | **重点中的重点**！按下面子顺序读          | 2 h 10 min |

#### `model/gpt2.py` 内部子顺序（**严格按这个顺序**，每步都能用上一步）

```
a) 文件顶部 import + `_build_sinusoidal_pos_emb`（L33-57）
   → 理解固定位置编码怎么算的

b) `CausalSelfAttention.__init__`（L82-119）
   → c_attn (n_embd → 3*n_embd) 一次性投 QKV
   → mask buffer (上三角)

c) `CausalSelfAttention.forward`（L121-185）
   → 形状变化: (B,T_q,C) → (B,H,T_q,D) → attn → (B,T_q,C)
   → KV cache 接口
   → causal mask 仅在 T_q == T_kv 时用

d) `MLP.forward`（L214-225）
   → 简单：升维 → GELU → 降维

e) `Block.forward`（L267-290）
   → Pre-LN: x = x + attn(LN(x)); x = x + mlp(LN(x))

f) `GPT2.__init__`（L323-400）
   → **weight tying** (L390): self.head.weight = self.tok_emb.weight
   → c_proj 缩小初始化 (L398-400)

g) `GPT2.forward`（L463-539）← **必看**
   → tok_emb + pos_emb → blocks → ln_f → lm_head
   → value_head 可选分支
   → cross_entropy(ignore_index=-100)

h) `GPT2.forward_with_kv`（L651-694）
   → 增量 forward（decode 阶段用）

i) `GPT2.generate`（L716-786）
   → 朴素 autoregressive（对照 generate_kv 理解 KV cache 的好处）

j) `GPT2.attach_value_head`（L808+）
   → PPO 用的 value_head 挂载
```

**产出**：能在白板上画出 `idx (B,T) → ... → logits (B,T,V) → loss` 完整数据流
