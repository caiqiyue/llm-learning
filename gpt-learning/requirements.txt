# =============================================================================
# 版本说明 & 已知坑
# =============================================================================
# 1) torch 限制 <3.0：2.x 之后 nn.MultiheadAttention 的 API 有变化，model/gpt2.py 自己写 attention 不受影响
# 2) tensorflow 限制 <3.0：3.x 移除了 tf.train.Checkpoint 等老 API，train_*.py 用的全是 2.x 写法
# 3) numpy 限制 <2.0：TF 2.13 在 numpy>=2.0 时会有 ABI 警告；本项目不要求 numpy 2.x 新特性
# 4) 不强制锁小版本是为了让 pip 能选到最适合当前 Python 解释器的 wheel
# 5) Python 版本：推荐 3.10；本机实测 D:\python311 的 torch DLL 损坏，请用 D:\python310
